# NIRVANA — The Path Within / V0.1

A contemplative, international, noncompetitive interactive 3D web sanctuary. The first vertical slice is the Lotus Sanctuary. No account, no leaderboard, no spiritual achievements, no depiction of Nirvana as a physical place. Visitors can walk around a lake, release glowing lanterns, start a 3/5/10 minute sitting session and enable optional synthesized ambient sound. React + TypeScript + React Three Fiber. Solo only. Privacy-first. Keyboard and touch controls. Reduced motion and low graphics modes.
